# Waygate

网络从你这台电脑出去，落在 Cloudflare 的另一头。

浏览器、终端、同一间屋子里的其他设备，填同一个地址就行。开着好几条线路时，新连接会自己找最顺的那条。

不需要管理员权限，也不需要装一块虚拟网卡。

## 开始

```bash
pip install -e .
waygate
```

这时代理在 `socks5h://127.0.0.1:1080`。

想看着它跑，并让多条线路一起分担：

```bash
waygate webui
```

打开 [http://127.0.0.1:8899](http://127.0.0.1:8899)。日常只用统一入口：

```text
socks5h://127.0.0.1:1079
```

地址用 **socks5h**。域名会跟着隧道走，不会留在本机。

确认自己已经在外面：

```bash
curl -x socks5h://127.0.0.1:1079 https://www.cloudflare.com/cdn-cgi/trace
```

看到 `warp=on` 就可以了。

## 常用

| 命令 | 做什么 |
| --- | --- |
| `waygate` | 只开一个代理，`127.0.0.1:1080` |
| `waygate webui` | 控制台加两条线路，入口在 `1079` |
| `waygate webui 3 1080` | 三条线路，从 `1080` 起 |
| `waygate check` | 自己走一遍，打印出口 |
| `waygate lan` | 代理开给局域网 |

Firefox：手动代理，SOCKS 主机 `127.0.0.1`，端口 `1079`，SOCKS v5，并让 DNS 也走代理。

Windows 系统代理那一栏是 HTTP，填进去不会生效。

控制台可以看每条线路的吞吐，复制地址，扫描更好的出口，再加一条或停掉一条。

身份记在用户目录里，下次启动会接着用。
